Configuration for GraalVM native-image (read automatically from the classpath).

Saxon-HE (XSL templates on export) loads some classes via reflection. Generated with the
tracing agent (`java -agentlib:native-image-agent=config-output-dir=...`) during an
export with an XSL template; only the entries for Saxon and xmlresolver were kept.

Kerberos on the server (`--keytab`): JAAS loads `Krb5LoginModule`, JGSS loads the mechanisms
via reflection. These entries were added by hand, not generated by the agent. Kerberos is
tested with the JVM server (Docker image).
